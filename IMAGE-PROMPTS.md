# Tamiko image prompts

Use these in ChatGPT, Gemini, Midjourney or any image tool. Save each image as a **.jpg** with the exact file name shown, about **1600 px on the long side**, and put them all in a folder called `images` next to `index.html`. The site picks them up automatically, with no code changes.

**Add this style line to the end of every prompt** so all images look like one family:

> Hand-painted anime film style inspired by Studio Ghibli, soft watercolour and gouache textures, warm natural light, gentle pastel sky with big fluffy clouds, cosy lived-in details, palette of soft navy blue, dusty rose pink, cream and sage green, calm and hopeful mood, no text, no logos, no brand names.

Tips: keep people's faces friendly and simple, and keep beauty experts gender-neutral (navy uniform, a small rose-pink "T" pin). Generate 2–3 options per prompt and pick the best.
